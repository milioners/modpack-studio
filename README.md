# ModPack Studio — конструктор модпаков для «Мира танков»

Программа для авторов модпаков. Вы собираете моды в проект, раскладываете их по группам,
оформляете — и получаете один установщик `.exe`, который отдаёте игрокам.

## Как пользоваться

1. **Новый модпак** (или «Пример модпака», чтобы посмотреть на готовый проект).
2. **Состав модпака** — перетащите в окно `.mtmod`, старые `.wotmod`, `.zip`-архивы или папки с модами.
   Раскладка по `mods/<версия>/` и `res_mods/<версия>/` определяется сама, картинка и readme из архива
   становятся превью и описанием. Моды перетаскиваются мышью: меняйте порядок, вкладывайте в группы.
   - группа **«Можно несколько»** — в установщике галочки;
   - группа **«Только один»** — кружки, игрок выбирает один вариант (прицелы, маркеры, озвучка);
   - галочка слева от мода — включён ли он по умолчанию.
3. **Оформление** — цвет, фон баннера, картинка приветствия, иконка, тексты. Справа живой
   предпросмотр установщика, список в нём можно щёлкать.
4. **Сведения** — название, версия, автор, для какой версии игры, параметры сборки.
5. **Сборка** — проверка проекта и кнопка «Собрать установщик». Готовый `.exe` лежит в `output/` проекта.

## Онлайн-каталог модов

Раздел «Каталог модов»: готовые моды с превью и описанием добавляются в проект одним кликом
(в выбранную группу). Если в каталоге вышла новая версия мода, в меню появляется счётчик,
а у мода — кнопка «Обновить». Каждый файл проверяется по контрольной сумме SHA-256;
моды только копируются в проект и никогда не запускаются.

Каталог — папка `catalog-online/` в репозитории программы (`index.json` + `mods/<id>/`):

```
node scripts/catalog.js add мод.zip --id my_sight --name "Мой прицел" --category crosshair --version 1.0 --preview p.png
node scripts/catalog.js build
```

После коммита в ветку `main` моды сразу видны всем. Адрес каталога можно сменить
в настройках программы (шестерёнка в заголовке) — например, на свой каталог.
Добавляйте только моды, которые разрешено распространять, и не из списка запрещённых Lesta.

## Версии и «Что нового»

В разделе «Сборка»: кнопки «+0.1» / «+1.0» поднимают версию модпака, а в поле «Что нового»
пишутся изменения. Игрок увидит их на отдельной странице установщика (последние три версии).
Там же — история сборок: все собранные установщики с версией, датой и размером.

## Что получает игрок

Установщик Inno Setup с баннером модпака, деревом модов, превью, описанием, автором и размером
каждого мода. Он сам находит игру и её версию (`version.xml`), предупреждает, если модпак собран
для другой версии, предлагает убрать старые моды (они переносятся в `modpack_backup`),
запоминает выбор при переустановке и удаляется через «Приложения» Windows.

## Проект модпака

Обычная папка: `project.json` (описание), `mods/` (копии файлов модов), `images/` (картинки),
`output/` (готовые установщики). Её можно копировать, архивировать и открывать на другом компьютере.

## Обновление самой программы

Программа сама проверяет GitHub Releases репозитория из `package.json` (`updateRepo`)
и предлагает обновиться: скачивает установщик, проверяет контрольную сумму и перезапускается.
Чтобы выпустить версию: поднимите `version` в `package.json`, опишите её в `CHANGELOG.md` и выполните

```
node scripts/release.js            # сборка и предпросмотр релиза
node scripts/release.js --publish  # публикация через GitHub CLI (gh)
```

## Разработка

```
npm install
npm start            # запустить программу
npm test             # тесты (нужен Inno Setup 6 для тестов сборки)
npm run dist         # установщик самой программы → dist/
```

Нужны Node.js 20+ и Inno Setup 6 (`winget install JRSoftware.InnoSetup`).
Используйте только разрешённые моды: за моды из списка запрещённых Lesta Games можно получить блокировку.
