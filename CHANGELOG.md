# История изменений TankAir Studio

## 2.0.0

- Программа теперь называется **TankAir Studio**. Настройки, недавние проекты и проекты модпаков переносятся сами; старые ярлыки заменяются новыми.
- Новый интерфейс: «стеклянные» панели поверх обоев, заголовок с поиском, обновлённая боковая панель с подсказкой «что сделать дальше».
- Раздел «Обзор» — обложка проекта: баннер модпака, цифры, подсказки «Что дальше» (ошибки, обновления модов в каталоге, несобранная версия, моды без превью и описания), лента версий и состав.
- Витрина модов: в «Составе модпака» можно переключиться со списка на карточки с превью, метками каталога и галочками «по умолчанию».
- Командная палитра Ctrl+K: поиск по модам проекта и каталога, разделам, действиям и настройкам. Ctrl+B — собрать установщик.
- Новый экран сборки: кольцо прогресса и этапы вместо журнала, карточка релиза с файлом, «Что нового» и кнопкой «Опубликовать», конфетти после успешной сборки.
- Оформление студии: темы «Тактика», «Сталь», «Хаки», «Неон», «Светлая», «Цвет модпака» и «Как в Windows», обои (градиент или баннер модпака), стеклянные панели, размер интерфейса, анимации.
- Исправлено: кнопка «Показать в папке» в истории сборок ничего не делала.

## 1.3.0

- Анимации элементов окна установщика: появление (проявление, выезд, увеличение, пружина) с задержкой, постоянные эффекты (пульсация, покачивание, мерцание свечения, вращение, мигание), реакция на наведение (увеличение, подъём, свечение), поворот.
- Градиентный текст, «матовое стекло» под фигурами, цвета кнопок при наведении, ВСЕ ЗАГЛАВНЫЕ.
- Медиа: видео на фоне экрана и видео-блок (mp4), фоновая музыка с кнопкой включения, звук нажатия на кнопки, слайдер картинок со стрелками и точками.
- Новые блоки: соцсети (Discord, Telegram, ВКонтакте, YouTube, Twitch, Boosty, сайт), счётчики, соглашение с обязательной галочкой, наборы модов («Рекомендуемый», «Минимальный» и свои).
- Свои экраны («О модпаке», «Авторы»…) с переходами по кнопкам; удаляются крестиком в списке экранов.
- Редактор: масштаб (Ctrl+колесо), линейки, группы (Ctrl+G), распределение с равным шагом, копирование стиля (Ctrl+Alt+C / V), автопроверка в настоящем окне после каждого изменения, экспорт и импорт дизайна одним файлом (.mpsdesign).
- Галерея из 8 готовых дизайнов с разным числом экранов (от 3 до 6) и своим оформлением: «Минимал», «Классика», «Презентация», «Комьюнити», «С соглашением», «Кинематограф», «Неон-аркада», «Светлый».

## 1.2.0

- Свой установщик модпака (ModPack Installer) вместо стандартного окна Inno Setup: карточки модов с превью, поиск, категории, подробное описание, экран приветствия, анимированная установка, экран «Готово» с запуском игры.
- Визуальный редактор окна установщика (как в Figma): каждый экран — холст, элементы двигаются мышью и меняют размер, привязка к сетке и направляющие, слои, отмена Ctrl+Z, копирование, выравнивание, условия показа («есть обновление», «игра найдена»…), кнопки с любыми действиями и ссылками, шаблоны раскладок, проверка в настоящем окне.
- Полностью настраиваемое оформление установщика: готовые темы, все цвета, фон окна с затемнением и размытием, шрифты, скругления, карточки или список, вкладки или меню, размер окна, тексты.
- Живой предпросмотр: в «Оформлении» показывается настоящий снимок окна установщика, есть кнопка открыть его для проверки.
- Кнопка «Обновить модпак» в установщике: новые версии берутся из GitHub Releases автора или с его сайта (update.json), проверяются по контрольной сумме.
- «Управление модпаком» в папке игры и в «Приложениях» Windows: обновление и удаление с возвратом заменённых файлов.
- Публикация версии модпака на GitHub прямо из раздела «Сборка».
- Классический установщик Inno Setup остался как вариант в «Сведениях».

## 1.1.0

- Автообновление программы: новые версии приходят из GitHub Releases, скачиваются, проверяются по контрольной сумме и ставятся в один клик.
- Онлайн-каталог модов: готовые моды с превью и описанием добавляются в проект одним кликом, обновления модов из каталога видны прямо в редакторе.
- Версия модпака и «Что нового»: кнопки «+0.1» / «+1.0», список изменений по версиям.
- Страница «Что нового» в установщике модпака.
- История сборок: все собранные установщики с версией, датой и размером.
- Тема окна установщика: светлая, тёмная или как в Windows.
- Галочка «Запустить игру» в конце установки.

## 1.0.0

- Первая версия конструктора модпаков: проект, группы «один из», оформление, сборка установщика Inno Setup.
