Возможности

Всё, что нужно автору модпака — в одной программе

Состав модпака — списком или витриной

Перетащите .mtmod, .wotmod, архивы или папки — раскладка по mods и res_mods определится сама, картинка и readme станут превью и описанием. Группы «можно несколько» и «только один» для прицелов и озвучек.

Редактор окна как в Figma

Каждый экран установщика — холст: двигайте блоки, меняйте цвета, шрифты, анимации, добавляйте видео, музыку, слайдер и соцсети.

Автообновление у игроков

Опубликуйте новую версию на GitHub или своём сайте — установщик и «Управление модпаком» сами предложат обновиться.

Онлайн-каталог модов

Добавляйте проверенные моды из каталога в один клик и узнавайте, когда автор выпустил новую версию.

Сборка в один клик

Кольцо прогресса, этапы, карточка релиза с «Что нового» и история всех собранных версий. Ctrl+B — и готово.

Удаление без следов

Старые моды уходят в резервную копию, а удаление модпака возвращает файлы игры в исходное состояние.

    Вопросы

    Частые вопросы

    Это бесплатно?

    Да. TankAir Studio бесплатна, исходный код открыт на GitHub.

    Какие моды поддерживаются?

    Пакеты .mtmod «Мира танков», старые .wotmod, zip-архивы и обычные папки с файлами для mods и res_mods. Раскладка по папкам версии игры определяется автоматически.

    Нужно ли игрокам что-то устанавливать?

    Нет. Игрок запускает один .exe: установщик сам найдёт папку игры, покажет моды с описаниями и превью и поставит выбранное. Удалить модпак можно из «Приложений» Windows.

    Как работает обновление модпака?

    Выберите в студии «GitHub Releases» или «Свой сайт». После публикации новой версии установщик и «Управление модпаком» в папке игры покажут кнопку «Обновить» и проверят файл по контрольной сумме.

    Не сломает ли модпак игру?

    Перед установкой старые моды переносятся в резервную копию modpack_backup, а при удалении модпака заменённые файлы возвращаются. Сама студия файлы игры не трогает.

    Какая Windows нужна?

    Windows 10 или 11, 64-бит. Для сборки установщика ничего дополнительно ставить не нужно.
