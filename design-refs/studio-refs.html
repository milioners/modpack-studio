ModPack Studio — референсы нового интерфейса

Шесть экранов одной системы: окно с эффектом «стекла» Windows 11, общий фон-обои, мягкие стеклянные панели, один акцентный цвет темы. Темы «Тактика», «Светлая» и «Неон» используют одни и те же компоненты.

Стекло и обои

Фон окна — градиент или размытая картинка из баннера модпака. Панели полупрозрачные, поэтому у каждого модпака студия выглядит по-своему.

Один акцент

Цвет темы — на активном пункте меню, главной кнопке, прогрессе и выделении. Остальное нейтральное.

Крупная типографика

Segoe UI Variable Display для заголовков и цифр, мелкие подписи приглушённым цветом.

Движение

Плавные переходы между разделами, карточки появляются по очереди, прогресс сборки и конфетти при публикации.
